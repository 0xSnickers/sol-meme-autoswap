# 多链 Meme 策略优化实施方案

## 1. 目标

当前策略保留“短周期动量 + 链上质量过滤 + 纸上交易”的核心，但从固定规则原型升级为可验证、可按链校准、包含真实摩擦的研究系统。

本方案不以增加指标数量为目标，优先解决会让纸上收益失真的问题：成交成本、跨链口径、退出保护和数据可验证性。

## 2. 当前主要问题

1. 纸上交易按快照价格成交，没有反映滑点、买卖税、Gas 和路由费用。
2. SOL、BNB Chain、Base 共用一套交易阈值，无法表达不同链的市场结构。
3. `tradeScore` 是人工阶梯权重，尚未经过分链、样本外数据校准。
4. TP1 后没有利润保护，剩余仓位可能从大幅盈利回落到原始止损。
5. 90 秒级动量信号只有 8 小时退出，缺少“入场后快速失败”处理。
6. 缺少被过滤候选币的完整特征和后续收益，无法可靠评估过滤条件。
7. 组合风控只有持仓数和资金使用率，没有单链、叙事和连续亏损约束。

## 3. 分阶段实施

### Phase 1：可信纸上成交与分链规则

- 建立统一的分链策略配置。
- `tradeScore`、最低流动性、成交量、买卖比等从对应链读取。
- 建立纸上成交成本模型：买卖滑点/税费按 bps 计算，并支持每次成交固定成本。
- 成本直接进入 Token 数量、卖出净回款和 PnL，避免只在页面展示但不参与结算。

初始分链门槛保持现有基线，先消除代码耦合，不假装已经完成参数发现。后续通过数据分别校准。

默认模拟摩擦：

| 链 | 买入成本 | 卖出成本 | 每次固定成本 |
|---|---:|---:|---:|
| SOL | 1.0% | 1.0% | $0.02 |
| BNB | 1.0% | 1.0% | $0.05 |
| Base | 1.0% | 1.0% | $0.03 |

这些是保守模拟假设，不是真实报价。实盘前必须替换为路由 Quote 或池子储备计算出的动态 price impact。

验收：同一行情价格下，纸上开仓得到的 Token 数量低于零成本模型；每次卖出净回款扣除卖出摩擦；不同链可以通过环境变量独立设置阈值。

### Phase 2：Meme 长尾退出保护

- `+80%` 时卖出足够数量，以扣除成交成本后的净回款收回全部初始本金。
- `+150%` 时卖出当时剩余仓位的 `50%`。
- 剩余 Token 作为长期尾仓，不再执行时间退出或快速失败退出。
- 尾仓若跌破实际买入成本价，卖出全部。
- 未触发止盈的持仓跌至 `-80%` 时全部止损。

验收：TP1 净回款不低于初始投入；TP2 按剩余仓位而非初始数量计算；尾仓可以长期存在，但不能跌破成本价后继续持有。

### Phase 3：研究数据集与参数校准

- 保存每轮所有候选币以及每个过滤条件的结果，而不仅是成功信号。
- 记录 5m、15m、1h、4h、8h 的收益、MFE、MAE、流动性变化和可卖出状态。
- 按 `chain × token age × score band × signal count` 统计净收益。
- 使用时间切分的训练期、验证期和样本外测试期，避免未来信息泄漏。
- 使用包含交易成本的中位数、分位数、最大回撤和 bootstrap 区间，不只看平均收益或 Sharpe。

验收：能够回答“被某条规则过滤的币后来表现如何”，并能为每条链生成独立参数报告。

### Phase 4：风险与组合控制

- 增加 holder/deployer/LP/代理合约/动态税率等独立 `riskScore`。
- 单链、单叙事和关联 deployer 持仓上限。
- 连续亏损冷却和单日最大回撤熔断。
- 每条链先保留候选名额，再进行全局排序，避免活跃链占满全部 8 个信号。

## 4. 配置约定

分链交易参数使用以下格式，`{CHAIN}` 为 `SOL`、`BSC` 或 `BASE`：

```env
SIGNAL_SOL_TRADE_SCORE_THRESHOLD=64
SIGNAL_SOL_TRADE_MIN_LIQUIDITY=15000
SIGNAL_SOL_TRADE_MIN_VOLUME=30000
SIGNAL_SOL_TRADE_MIN_BUY_SELL_RATIO=1.4

SIGNAL_SOL_EXECUTION_BUY_COST_BPS=100
SIGNAL_SOL_EXECUTION_SELL_COST_BPS=100
SIGNAL_SOL_EXECUTION_FIXED_COST_USD=0.02
```

退出保护：

```env
SIGNAL_PAPER_TP1_PROTECTION_PERCENT=0
SIGNAL_PAPER_FAST_FAILURE_MINUTES=0
SIGNAL_PAPER_FAST_FAILURE_LOSS_PERCENT=0
```

旧的全局 `RADAR_TRADE_*`、`RADAR_PAPER_*` 配置继续兼容，分链配置优先。

## 6. 风险说明

所有默认参数都只是策略假设，不构成收益保证。Phase 1 和 Phase 2 的目的，是降低纸上结果的乐观偏差并提供可校准结构；在 Phase 3 完成前，不应把当前纸上结果当作可实盘复制的收益。

# 策略复盘 2026-05-05

## 当前样本结论

- 运行约 `18h+`，已实现盈亏 `-118.72 USD`
- 已平仓 `13` 笔，胜率仅 `15.4%`
- 关闭原因里 `stop_loss_40` 占 `10` 笔，说明主问题不是偶发黑天鹅，而是系统性让亏损单走到深止损
- 亏损样本大量集中在 `tradeScore 75-84` 区间，说明旧版 `tradeScore >= 73` 过松，而且评分对 `smart money` 权重偏高

## 旧版主要问题

### 1. 大止损吞掉太多样本

- 旧版止损 `-40%`
- 旧版 TP1 在 `+40%`
- 结果是很多单子在没有先兑现利润前，直接回撤到大止损

这会同时伤害:

- 胜率
- 盈亏比
- 资金曲线稳定性

### 2. 评分过度偏向 smart money

旧版高分票里，很多单子虽然:

- `smart money` 高
- `liq` 和 `volume` 不差

但:

- `buy/sell ratio` 只在及格线附近
- `1h` 涨幅已经偏热

这类票仍然可以轻松拿到 `80+` 分，导致“看起来很强，但进场后承接不足”。

### 3. 组合同时打开过多仓位

旧版默认:

- 基础仓位 `50 USD`
- 最多 `8` 个打开持仓
- 最大资金使用率 `65%`

这对高波动 Meme 环境仍然偏激进。

## v1.2 调整目标

- 减少边缘信号进入交易层
- 更早兑现利润，避免盈利单回吐成亏损单
- 缩小单笔最大回撤
- 降低同时暴露的仓位数量

## v1.2 默认参数

### 交易层

- `tradeScore >= 76`
- `smartMoney >= 3`
- `signalCount <= 1`
- `liquidity >= 15000`
- `volume >= 30000`
- `buySellRatio >= 1.4`
- `1h 涨幅 >= 50%` 进入高热模式
- 高热模式要求:
  - `tradeScore >= 82`
  - `smartMoney >= 6`
  - `liquidity >= 30000`
  - `buySellRatio >= 1.6`

### 账户与仓位

- 基础仓位 `40 USD`
- 最多 `4` 个打开持仓
- 最大资金使用率 `25%`

### 平仓结构

- 止损 `-25%`
- `TP1 +25%` 卖出 `55%`
- `TP2 +60%` 卖出 `25%`
- `TP3 +120%` 卖出 `20%`
- `+35%` 启动 trailing
- trailing 回撤 `15%`
- `6h` 未到 TP1 触发时间止损

## 预期效果

- 胜率应明显高于旧版
- 单笔亏损从 `-40%` 级别收敛到 `-25%` 左右
- 已实现盈亏不再严重依赖极少数大肉单
- 新开仓频率下降，但组合波动更小

## 观察重点

- `stop_loss` 命中次数是否明显下降
- `TP1` 命中率是否明显上升
- 新开仓是否稳定少于旧版
- `tradeScore 76-79` 区间是否仍然表现差

如果 `76-79` 这档后续继续拖累结果，下一步优先把 `tradeScore` 下限继续上调到 `78-80`。

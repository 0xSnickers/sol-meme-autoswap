# 策略复盘 2026-05-01 13:45

## 本次背景

上一版引入了 `1000 USD` 纸上账户和持仓面板后，真实跑了十几分钟，暴露出一个很明显的问题:

- 仓位打得太快
- 打开持仓过多
- 盈利比例不高
- 账户权益下降明显

观察到的典型现象是:

- 很短时间内资金使用率接近 `80%+`
- 已实现盈利只有很少一部分
- 打开中的浮亏反而迅速扩大

这说明当前系统的问题已经不是“有没有信号”，而是“交易层太宽，组合风控太松”。

## 上一版为什么会出问题

上一版 `v1-paper` 的核心问题有 3 个:

### 1. 开仓门槛偏低

之前允许自动开仓的条件里:

- `tradeScore >= 70`
- `signalCount <= 2`

这会放进不少“能看，但不值得自动买”的票。

### 2. 组合暴露过高

虽然加了总资金 `1000 USD`，但只限制了“不能超过总余额”，没有限制:

- 最多能同时开多少个仓
- 最多允许占用多少资金

结果就是:

- 一个市场环境里连续打开很多相关风险仓位

### 3. 盈亏比失衡

上一版使用:

- `TP +20%`
- `SL -50%`

这意味着即使胜率不低，只要出现少量大回撤，也很容易把前面的盈利吞掉。

## 本次 v1.1 收紧目标

本次不修改信号层，只收紧交易层。

这样做的目的很明确:

- 保留雷达的发现能力
- 收紧自动执行纪律
- 让后续复盘能清楚区分“发现问题”还是“执行问题”

## 本次具体调整

### 1. 提高交易评分门槛

从:

- `tradeScore >= 70`

调整为:

- `tradeScore >= 80`

目的:

- 过滤掉边缘信号
- 只让更强的交易机会进入纸上账户

### 2. 只允许第 1 次信号开仓

从:

- `signalCount <= 2`

调整为:

- `signalCount <= 1`

也就是:

- 只允许第 `1` 次信号自动开仓
- 第 `2` 次及以后只记录，不追买

原因:

- 第 `2` 次及以后信号更容易发生在趋势中后段
- 对自动交易来说，追高风险明显更大

### 3. 限制最大打开持仓数

新增:

- `最多 4 个打开持仓`

原因:

- 防止短时间内打出过多仓位
- 降低同一市场环境下的相关性风险

### 4. 限制最大资金使用率

新增:

- `资金使用率 <= 50%`

口径为:

- 当前打开持仓总买入成本 / 总资金

只要新开仓后会超过 `50%`，该笔交易直接拒绝。

目的:

- 保留足够现金
- 避免在一轮市场躁动里满仓追进去

### 5. 降低基础仓位

从:

- `100 USD`

调整为:

- `60 USD`

这样即使高分票获得更高 multiplier，总体风险也会比上一版温和很多。

### 6. 收紧止损

从:

- `SL -50%`

调整为:

- `SL -25%`

止盈暂时保持:

- `TP +20%`

这样虽然还不是最优的赔率结构，但已经明显比上一版健康。

## 本次版本默认参数

当前默认交易层参数为:

- `tradeScore >= 80`
- `smartMoney >= 3`
- `signalCount <= 1`
- `liquidity >= 5000`
- `volume >= 20000`
- `buySellRatio >= 1.2`
- `最多 4 个打开持仓`
- `最多使用 50% 资金`
- `基础仓位 60 USD`
- `止盈 +20%`
- `止损 -25%`

## 本次预期

这次升级后，预期变化不是“交易次数更多”，而是:

- 交易次数变少
- 资金占用变低
- 打开持仓数量显著减少
- 组合波动下降
- 单笔最坏亏损明显收敛

如果后面跑出来的数据符合这些方向，就说明这次收紧是有效的。

## 后续观察重点

接下来重点看 5 个指标:

- 打开持仓数是否稳定压在 `4` 以内
- 资金使用率是否稳定压在 `50%` 附近或以下
- 已平仓中 `+20%` 止盈和 `-25%` 止损的比例
- 第 `1` 次信号的胜率是否高于旧版总体表现
- 账户权益曲线是否比旧版更平滑

## 下一步可能的继续优化

如果这一版仍然不理想，下一步优先级建议是:

- 把止盈从单点 `+20%` 改成分批止盈
- 增加时间止损，防止长时间横盘占用资金
- 提高 `tradeScore` 对 `1h 涨幅过热` 的惩罚
- 对高相关叙事币增加同主题持仓限制

## 本次结论

`v1.1` 的核心思想不是“找到更多币”，而是:

- 宁可少做
- 也不要在高相关的 MEME 环境里快速把仓位打满

这一版更接近真实可执行的自动交易纪律，也更适合作为后续接 GMGN 真仓前的过渡风控版本。

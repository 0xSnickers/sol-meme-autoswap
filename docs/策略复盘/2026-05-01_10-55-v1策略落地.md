# 策略复盘 2026-05-01 10:55

## 本次目标

按照上一版复盘建议，先落地第一个可运行版本，但暂时不直接连接 GMGN 真仓交易。

本次实现的方向是:

- 保留现有信号层
- 新增 `tradeScore`
- 新增 `paper trade`
- 新增固定止盈止损

同时根据本次要求，把止损从保守版改成:

- `止盈 +20%`
- `止损 -50%`

## 本次已实现规则

### 1. 信号层

仍然沿用当前雷达:

- 仅扫描 `SOL`
- `30s` 一轮
- 连涨 `3` 轮
- 总涨幅 `>= 5%`
- `聪明钱 >= 2`
- 流动性、持有人、成交量、买卖比、社交、安全检查通过

### 2. 交易评分层

新增 `tradeScore`，用于决定是否允许纸上开仓。

当前打分因子:

- 聪明钱数量
- 信号出现次数
- 流动性
- 1h 成交量
- 买卖比
- 1h 涨幅过热惩罚

### 3. 自动开仓条件

当前第一版允许纸上开仓必须同时满足:

- `tradeScore >= 70`
- `smartMoney >= 3`
- `signalCount <= 2`
- `liquidity >= 5000`
- `volume >= 20000`
- `buySellRatio >= 1.2`
- 当前该 Token 没有打开中的纸上持仓

### 4. 平仓条件

当前第一版链上模拟交易平仓规则:

- `+20%` 自动止盈
- `-50%` 自动止损

## 为什么这版这样做

这版的目标不是追求最优收益，而是先建立完整交易闭环:

- 信号
- 打分
- 决策
- 开仓
- 持仓更新
- 平仓
- 结果持久化

这样后面接 GMGN 真实交易时，只需要把“纸上开仓/平仓”替换成真实执行层即可。

## 为什么接受 -50% 止损

对于常规交易，这个止损过宽。

但在你当前目标里:

- 市场是高波动 Meme
- 你已经明确接受高风险
- 第一版主要目的是验证“信号转交易”的闭环

所以本次按你的要求使用:

- `SL = -50%`

不过需要明确:

- 这会显著提高单笔回撤
- 后面接入真实仓位时，必须用更小仓位控制风险

## 对第一版的预期

第一版最重要的验证点不是“赚多少”，而是:

- 哪些信号真的会进入纸上持仓
- `signalCount` 对结果影响有多大
- `smartMoney` 和收益是否有明显相关性
- `+20% / -50%` 这个组合是否合理

## 下一步建议

第一版跑一段时间后，重点看这几个维度:

- `第1次信号` 和 `第2次信号` 的胜率差异
- `smartMoney 3-4` 与 `>=5` 的收益差异
- 触发 `+20%` 的比例
- 命中 `-50%` 的比例

如果后面发现:

- `第2次信号` 明显变差
  - 就把自动开仓限制成只允许 `第1次`
- `smartMoney=3` 表现很差
  - 就把门槛提高到 `>=4`
- `-50%` 止损命中太多
  - 说明策略过于宽松，应该收紧买入条件，而不只是改止损
